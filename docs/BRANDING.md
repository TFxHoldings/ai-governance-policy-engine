# TFx Branding

The public web application uses the TFx Holdings logo and a visual system derived from it.

## Core palette

- Deep Navy: `#011e37`
- Navy: `#071c32`
- Mid Navy: `#072c43`
- Teal: `#36c3b4`
- Soft Teal: `#65d5c3`
- Lime: `#85dca5`
- Soft Lime: `#a7e6b6`
- Cyan: `#4bc9d0`

## Usage

The TFx logo should remain visible in the primary application chrome and footer. Product UI accents should use the teal-to-lime family rather than introducing unrelated brand colours.
